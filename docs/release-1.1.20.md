# KennysVideo 1.1.20 · Windows / Android

同一发行版提供 Windows 安装版、免安装版、Android APK 和完整源码；请按设备选择安装文件。

## Windows 电脑端
- ↑ / ↓ 每次调节音量 5%，← / → 每次后退/快进 5 秒；保留空格播放暂停。
- 输入框、反馈表单、弹窗及控制锁定时不拦截方向键，避免影响文字编辑。
- 更新进度条上方显示电脑端更新内容，下载过程中保留，可滚动阅读。

## Android 手机端
- 左右滑动预览快进或后退目标，松手后跳转。
- 左侧上下滑动调当前窗口亮度，右侧上下滑动调媒体音量，显示百分比。
- 避开进度条与按钮，兼容控制锁定、长按倍速和多指取消；返回首页恢复系统亮度。
- 更新进度条上方显示手机端更新内容，下载过程中保留，可滚动查看。

## 安装说明
旧版客户端的界面不会因更新清单而自行改变；安装 1.1.20 后，后续软件内更新才会显示新增的更新内容区域。Android 仍需系统确认安装，沿用相同包名和测试签名。最低 Android 7，支持 ARM64/x86_64；旧设备需更新 WebView。

## English
Windows: added arrow-key volume/seeking shortcuts with input-field protection. Android: added horizontal seeking, left-side window brightness and right-side media-volume gestures. Both editions display their own release notes above the download progress bar. The new update interface takes effect after installing this version.
