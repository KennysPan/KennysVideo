# KennysVideo 1.1.16

## 反馈提交修复

- 修复首页的影视 API 请求拦截器误拦截外部反馈接口，导致报告未发送到服务器的问题。拦截器现在只处理同源的搜索与详情路由。
- 问题描述不再要求至少 10 个字符，填写非空内容即可提交。前后端规则同步，保留最大长度限制和基本格式校验。
- 对格式错误、来源拒绝、编号冲突和内容过大提供具体提示。失败保留填写内容；编号冲突后可直接重试。
- 回归测试加载真实请求拦截脚本，覆盖单字符描述提交。后端 9 项本地 HTTP、存储与邮件模拟测试通过。
- 完整前端向 HTTPS 服务真实提交返回 202，服务器确认测试邮件发送状态为 sent；本机测试使用公网域名解析以避免代理私网 DNS 映射，保留 HTTPS 证书校验。此检查为 Edge 浏览器验证，未将其表述为原生 WebView2 完整验收。

## 安装与开源

首页使用声明增加网络资源来源、视频源责任、侵权反馈渠道及“切勿相信视频中的广告”提示。每次完整启动软件均显示，同一次运行内切换页面、播放后返回首页不重复弹出；确认声明不会改动推荐开关等已有设置。

Windows x64 安装包支持覆盖升级，另提供免安装版与完整源码。保留 GitHub 优先、超时或低速回退 Gitee 的更新策略及 SHA256 校验。
