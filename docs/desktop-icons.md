# Windows 快捷方式图标刷新

EXE 的图标资源已更换，但现有快捷方式的 IconLocation 为空时会继续通过固定 EXE 路径使用 Windows 的缓存图标。仅发送全局刷新通知不能保证这一缓存条目失效。

安装器现在在安装目录保存 KennysVideo-版本.ico。新建快捷方式明确引用该文件；覆盖安装成功后，刷新桌面、开始菜单及已固定任务栏快捷方式的图标位置。只修改目标为本次安装的主程序 EXE 的现有链接，保留目标、参数、固定位置和 AppUserModelID；不操作其他应用、不重启 Explorer、不删除系统图标缓存数据库。旧快捷方式因更新模式被跳过创建时，也会执行刷新。

安装完成后通知 Shell 刷新。卸载时清理安装目录中本应用版本图标。普通窗口与托盘仍使用相同新图片的原生图标资源。
