# KennysVideo 1.1.22 · Windows / Android

## Windows
- 默认开启豆瓣 API 模式，升级时自动开启一次，之后保留手动选择。
- 更新弹窗锁定背景滚动，转到后台下载后恢复页面操作。
- 下载完成后三个按钮同排，安装包校验成功后自动打开安装程序。

## Android
- 默认开启豆瓣 API 模式，与电脑端保持一致。
- 启动声明采用紧凑卡片、独立滚动正文和固定确认按钮。
- 更新时锁定背景页面，三按钮保持单行。
- 下载并校验成功后自动打开系统安装界面，首次仍需允许安装来源，系统确认后安装。

## 下载
提供 Windows 安装版和便携版、Android ARM64/x86_64 APK、完整源码和双端更新清单。手机更新包为同一 APK，沿用原测试签名。

本版界面与自动打开安装器的行为在安装 1.1.22 后生效；旧版下载本版时仍使用旧版界面。
