# Windows 关闭确认

每次重新显示确认弹窗，始终默认选中“最小化到系统托盘”，不沿用上次未记住的退出选择；记住选择时仍按用户明确保存的行为直接处理。

点击标题栏关闭或 Alt+F4 时，原生 CloseRequested 事件先阻止直接销毁窗口，再显示当前页面上的模态弹窗。首页、播放器、关于等页面均在加载完成后注入同一处理程序。

默认选择“最小化到系统托盘”。“确定”执行选定操作；“取消”和 Esc 均不执行操作、不保存变动。勾选“下次不再提示”后，下次关闭由原生代码直接执行已记住的操作。系统托盘在应用启动时创建；只有存在托盘图标才允许隐藏窗口。隐藏后任务栏按钮消失，进程继续运行。单击/双击托盘图标或再次启动软件可恢复主窗口，右键菜单可显示主窗口或直接退出。标题栏的普通最小化按钮保持 Windows 标准行为。

设置 → 关闭按钮行为 可切换“每次询问”“最小化到系统托盘”“退出程序”。保留原有 minimize 存储值以继承上一版记住的选择。偏好保存在原有应用配置目录 close-preference.json，覆盖升级后仍保留，不依赖网页 Cookie。文件缺失或损坏时恢复每次询问；保存失败则弹窗显示错误，不直接退出。更新安装通过原有 app.exit 路径退出，不受该弹窗阻碍。

托盘图标位于通知区域，是否折叠到 ^ 隐藏栏由 Windows 管理，用户可拖动调整。应用不修改系统通知区域偏好。

设置页六个区域共用同一列容器及 settings.css；修正豆瓣推荐开关后的多余结束标签，将豆瓣 API 模式和其余设置放回对应容器。各卡片宽度、间距、控件字号及高度一致。

验证：tests/windowClose.cjs 测试真实弹窗 DOM（原生 IPC 使用可控适配器），涵盖取消、Esc、操作与记住选择、设置重置、重复关闭请求、保存失败及小窗口。Rust window_close 单元测试验证偏好文件保存/重新加载及损坏回退。生产 Windows 编译验证原生事件与命令的接线。
