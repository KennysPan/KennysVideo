# KennysVideo 1.1.35 · Windows / Android

## Windows 更新
- 搜索最多 6 个并发请求，新搜索丢弃旧搜索待发任务，停止过时分页及近似搜索。
- 合并同帧结果刷新，缓存标题匹配分数，减少重复计算。
- 首批展示 60 条结果，可通过“显示更多”继续查看全部结果。

## Android 更新
- 同步搜索并发限制、过时任务停止及分批显示，降低连续搜索与大结果列表负担。
- 手机端“手动下载”固定使用 Gitee 发布页。
- 保留设置、观看记录、主题、配置及原 Android 签名，可覆盖升级。

## 验证与限制
本地模拟压测的峰值并发请求从 1,000 降至 6；浏览器 2,000 条结果场景改为首批 60 条后，首批渲染中位耗时从约 643 ms 降至 16.6 ms。数据来自本地模拟，不能代表真实网络或手机性能；尚未进行 Android 真机性能验证。已经发出的原生请求仍会正常结束，不强制中断。

Windows 与 Android 同版发布。附件包含 Windows 安装版、便携版、Android APK、完整源码、更新清单、校验文件及更新说明。不发布 Mac/Linux 安装包。
