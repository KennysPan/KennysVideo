# 1.1.14 发布改动

以下累计改动纳入 1.1.14，正式发布说明见 release-1.1.14.md。

## 播放界面广告提示

- 每次进入播放页面时，弹窗显示“切勿相信视频中的广告”，确认后才初始化播放器。
- 使用深色主题弹窗和“我知道了，继续观看”按钮；同一播放页面内切集、自动连播不重复提醒。
- 移除画面上的常驻提示，确认后视频画面不显示该提示。
- 已纳入 1.1.14 正式构建。

## 数据源专区

- 底部增加“片库”入口；自定义 API 设置列表提供“进入片库”按钮。
- 选择一个自定义或内置来源，独立浏览、分类、翻页和搜索，不修改聚合搜索的来源选择。
- 点击影片衔接原有详情、剧集和播放流程；兼容根地址或完整采集接口地址。
- 加入空列表、接口不兼容、加载失败、重试与响应乱序处理，保留内容过滤与默认封面。
- 技术约定与验证方式见 source-catalog.md。

## BUG 反馈（自建 HTTPS 服务与 HTML 邮件）

- 设置页与播放页加入“反馈 BUG”入口，填写标题、问题描述、复现步骤与可选回复邮箱。
- 使用维护者的 HTTPS 服务持久保存报告，由服务器通过 QQ SMTP 发送；加入发送状态、失败保留输入及重试去重。
- SMTP 授权码只保存在服务器；客户端不含邮箱凭据，旧 Web3Forms 通道已停用。
- 8 项服务端测试、弹窗回归、HTML 输入转义及邮件窄屏布局检查通过。
- 禁用 HTTP 代理的真实前端提交返回 202，服务器发送状态为 sent；维护者确认实际收件和 HTML 配色、头像与排版正常。
- 原生 WebView2 自动化验收尚未完成；验证范围详见 bug-feedback.md。
